# Ottly 知因趣码——面向编程初学者的 Python 智能自适应学习平台

> 参赛作品简介：Ottly知因趣码是一款面向编程初学者的Python智能自适应学习平台，针对“报错看不懂、改对未理解、练习缺方向”等学习难点，构建“学习—实践—诊断—巩固”的学习闭环。
> 平台设置十二个情境化关卡，融合知识讲解、AI互动问答、概念小测与在线编程，通过逐行执行回放帮助学生理解程序逻辑。系统结合实际运行结果分析错因、识别疑似认知误区，并在学生改对后推荐针对性练习。通关后，可根据学习记录生成挑战题，经校验与审核后开放作答。
> 作品将代码执行证据与大语言模型相结合，让错误成为个性化学习的依据，帮助学生从“做对一道题”走向“理解一类题”。

## 一、项目概述
### （一）项目背景与意义：初学者难以理解报错、纠正认知误区及选择后续练习。
Python初学者在编程练习中，不仅需要掌握语法规则，还需要理解代码执行过程，并建立变量、条件、循环与函数等概念之间的联系。面对程序报错或判题失败，学习者往往难以从异常信息和输出结果中找到问题根源。例如，循环结果不符合预期，可能涉及循环范围、变量初始化位置或更新顺序等不同原因，仅凭“答案错误”难以确定需要修正的理解。
同时，代码修改正确并不必然意味着相关知识已经掌握。学习者可能通过反复尝试或参照答案完成当前题目，但在情境变化后仍出现相似错误。如果后续练习与此前暴露的问题缺乏关联，就难以进一步检验理解和巩固知识。因此，编程入门学习需要将错误解释、执行过程观察和针对性练习连接起来，为学习者提供连续的支持。
针对上述问题，本项目设计并实现了“Ottly知因趣码”Python智能自适应学习平台，以十二个情境化关卡串联知识讲解、互动问答、概念小测和编程实践。系统通过实际代码执行与测试获得判题依据，再结合公开输出、异常信息及输出差异生成教学反馈；通过真实执行轨迹回放展示变量与输出的变化，并支持按需解释指定步骤，帮助学习者理解代码与运行结果之间的关系。
在后续巩固环节，系统记录正式提交中的失败与修正过程，在主线题由失败转为通过后，结合知识点和可信的疑似误区标签推荐加练。完成主线课程后，学习者还可进入无尽挑战，使用题库练习或经过校验的个性化生成题。项目由此形成“学习—实践—诊断—巩固”的学习闭环，为Python入门教学和自主练习提供可运行的辅助工具，并为进一步研究基于错误证据的个性化学习支持提供实践基础。
### （二）赛题方向定位：结合正式赛题要求，说明人工智能与编程教育的结合方式。
本项目围绕算法创新赛“AI+软件创新”方向展开，定位为面向Python初学者的人工智能辅助学习软件。该方向强调人工智能技术与软件核心功能的融合，以及从需求分析、架构设计到开发测试和产品交付的完整实现过程。本项目以编程学习中的错误理解与练习安排为应用场景，将大语言模型嵌入具体教学环节，体现人工智能技术在学习支持中的应用价值。
在技术实现上，平台采用React前端、FastAPI后端和MySQL数据库，通过Python执行服务获取运行结果及执行轨迹，由后端统一调用DeepSeek API完成问答、错因分析、学习引导和挑战题生成。系统以实际测试结果确定判题与通关状态，模型围绕可公开的执行证据提供解释，模型输出经过相应校验后进入学习界面。
项目的核心设计集中在人工智能能力与教学流程的协同。首先，根据执行结果选择反馈方式：运行异常或全部测试失败时提供错因分析，部分测试通过时提供检查方向和可选概念小测。其次，将错误修正与后续练习衔接，通过规则筛选、候选排序及必要的模型辅助选择推荐加练；当前自适应能力主要体现为练习内容的针对性安排。最后，结合真实执行回放与按需步骤讲解支持过程理解，并对生成题实施结构检查、参考解执行和边界测试审核。
本项目的创新重点在于执行证据组织、差异化反馈、练习推荐和生成题验证等应用机制。平台通过Docker组织本机运行环境，支持完整学习流程的演示与复现，为评审检查核心功能和技术实现提供条件。项目的教学价值将在后续真实试用中，通过反馈质量、任务完成情况和知识迁移表现进一步验证。
