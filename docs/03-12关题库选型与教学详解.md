## 第 01 关：初识小海獭

**前置与目标：** 无编程前置；学会 K01。先解释英文括号、成对引号以及空格也是字符。

**情境：** 浪花把一只小海獭冲上了沙滩，她叫 Ottly。

Ottly 还不会说人类的语言，她只会用你的程序说话——屏幕上打出什么，她就说什么。

在编程世界里，每一个新朋友开口说的第一句话都是一样的。这是从 1972 年流传下来的老规矩，几十年来所有学编程的人都从这一句开始。

现在轮到你了。帮 Ottly 说出她在人类世界的第一句话。

**知识点讲解：**
1. 代码和输出
你可以这样想：你对 Ottly 说"请念出 Hello, World!"。她会念"Hello, World!"，不会把"请念出"三个字也念出来。

2. print 这条指令的三个部分
```
print("Hello, World!")
└─┬─┘└──────┬──────┘
  │         └── 第三部分：要念出来的内容
  └── 第一部分：函数的名字
     └─ 第二部分：一对英文圆括号，是"喂给它东西"的入口
```
| 部分 | 作用 | 注意 |
| print | 函数的名字，可以理解为 Ottly 的嘴巴 | 四个字母都是小写 |
| ( ) | 英文圆括号，把要念的东西括起来 | 必须是英文半角，而且必须成对 |
| "Hello, World" | 要念出来的内容 | 必须用引号包住 |

```
SyntaxError: invalid character '（' (U+FF08)
这个报错的意思是："我在这行里看到了一个我不认识的字符。" U+FF08 就是中文全角左括号的编号。
```

3. 空格也是一个真实的字符
空格不是"没有东西"。它是一个字符，和字母一样占一个位置，一样会被逐字比较。

4. print 会自动换行
print 每次执行完，自动跳到下一行。所以你不需要自己写换行符——只要正确地写完这一句，回车就自动加上了。

本关只需要输出一行，所以你只要写一条 print。

**任务：**不需要任何输入。 用 print 输出一行：
```
Hello, World!
```

**参考解：**

```python
print("Hello, World!")
```

**三级提示：** L1：我们想让 Python 显示一段文字，它怎么知道这段文字从哪里开始、到哪里结束？L2：看第 1 行 print 后面的那对圆括号，里面的文字有没有被引号包住？再确认引号是英文的还是中文的。L3：请把要显示的文字用一对英文引号包起来，然后对照题面逐字检查大小写、逗号和感叹号，再提交。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `""` | `"Hello, World!\n"` | 精确输出 |

来源关联：futurecoder 字符串基础；保留本项目现有入门任务。

## 第 02 关：打招呼

**前置与目标：** K01；学习 K02。先讲赋值“先算右侧，再把结果交给左侧名字”，再讲 input 返回一行文本，以及字符串用 + 拼接。print 多个参数默认以一个空格分隔。

**情境：** 上一关，Ottly 学会了她人生中第一句话。
现在她想向朋友们问好——第一位叫 Amy，第二位叫 Sea Otter……Ottly 想让每一位朋友都听到自己的名字。

**知识点讲解：**
1. 变量 = 一个贴了标签的盒子
变量不是"名字"，是一个装东西的盒子，盒子上贴着标签便于你找到它。

赋值：先算右边，再把结果放进左边的盒子。右边的先发生，左边后发生。
取值：写出盒子的标签，得到的是盒子里的内容。

2. 为什么变量名不能加引号？
| 写法 | 含义 |
| name | 盒子里的内容（朋友真正的名字）|
| "name" | 四个固定字母 n-a-m-e |
加了引号，就从"取盒子里的东西"变成了"一段固定文本"。

3. 那个空格是从哪来的？
输出里的 Hello, Amy! 中间有一个空格。它可能来自两个地方，而这两种写法看起来一样、实际不同：

来自两个输出项之间：打印时自动插入一个空格
来自字符串末尾：你自己在引号里多写了一个空格
如果你两个都用了，就会出现两个空格 → Hello, Amy!。

4. 变量必须先装东西，才能取
代码是从上往下执行的。如果打印写在读取输入之前，盒子里还是空的，程序会直接报错。

**任务：**输入一行姓名（1–20 个字符，不含首尾空格，可以含内部空格）。

把输入保存到一个变量里，然后输出：
```
Hello, 姓名!
```
**样例：**
| 输入 | 输出 |
|---|---|
| Amy | Hello, Amy! |
| Tim | Hello, Tim! |

**参考解：**

```python
name = input()
print("Hello,", name + "!")
```

**三级提示：** L1：问候语中哪部分会随输入变化？L2：查看变量是否真正接收了输入，打印时有没有把变量名加上引号。L3：把输出分成固定前缀、姓名和标点三部分，检查连接处的空格。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"Amy\n"` | `"Hello, Amy!\n"` | 基本姓名 |
| 隐藏 | `"Ottly\n"` | `"Hello, Ottly!\n"` | 防止固定姓名 |
| 隐藏 | `"Sea Otter\n"` | `"Hello, Sea Otter!\n"` | 内部空格 |
| 隐藏 | `"小海獭\n"` | `"Hello, 小海獭!\n"` | 中文文本 |

来源关联：futurecoder 变量与字符串章节；姓名牌题面自编。

## 第 03 关：贝壳小商店

**前置与目标：** K02；学习 K03。先用短示例对比字符串相加和整数相加，再讲 int、+、-、* 和运算优先级。本题只需乘法与减法。

**情境：**上一关，Ottly 学会了向每个朋友打招呼。

现在她在海边支起一个小摊卖自己捡来又打磨过的贝壳。生意出乎意料地好——麻烦也跟着来了：

顾客说"我要 3 个"，她掰着手指头还勉强算得清；可有人一口气要 100 个，她就有些忙不过来了。
请你写一个程序，帮她算出：
1.顾客总共花费了多少
2.Ottly 需要找零多少给顾客

**知识点讲解：**
1. 数字与文字的区别

Ottly 报价 4，你的程序收到的其实是文字 "4"——一个字符，而不是可以计算的数字 4。上一关装名字的盒子，这一关要装数字，就得先把文字"翻译"过来。

2. 文字相加和数字相加，结果完全不同
先看一个例子：

| 写法 | 结果 | 发生了什么 |
|---|---|---|
| 文字相加‘4’+‘3’ | 43 | 两个字符首尾接在一起 |
| 数字相加4+3 | 7 | 真正的算术加法 |
同样是加号，两边是文字就是"拼接"，两边是数字才是"计算"。

3. 用 int 把文字翻译成整数
int 的作用就是把取到的文字变成真正的整数。转换要发生在计算之前，否则后面得到的都是错误答案。

4. 乘法求总价，减法求剩余
总价：每件价格都一样，买若干件就是重复若干次 → 用乘法
找零：顾客带的总钱数，减去这次要付的 → 用减法

**任务：**依次输入单价 price（1–100）、数量 quantity（0–100）和支付金额 budget（0–10000）。

输出：总价、找零，均为整数，不附单位。

**样例：**
输入：（第一行代表单价，第二行代表数量，第三行代表支付金额）
```
4
3
20
```
输出：（第一行代表总价，第二行代表找零）
```
12
8
```

**参考解：**

```python
price = int(input())
quantity = int(input())
budget = int(input())
cost = price * quantity
remaining = budget - cost
print(cost)
print(remaining)
```

**三级提示：** L1：每位顾客买走好几件，Ottly 该怎么算出这一次要收多少钱？L2：看读取三行输入的地方有没有把文字转成整数，再看算总价那一行用的是乘法还是加法。L3：请先把总价算出来存进一个变量，再用支付金额减掉它；最后按任务要求一行一行输出。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"4\n3\n20\n"` | `"12\n8\n"` | 普通购买 |
| 隐藏 | `"7\n0\n10\n"` | `"0\n10\n"` | 数量为零 |
| 隐藏 | `"5\n4\n20\n"` | `"20\n0\n"` | 预算恰好用完 |
| 隐藏 | `"100\n100\n10000\n"` | `"10000\n0\n"` | 范围上限 |

来源关联：Currency Exchange 的乘法总额与余额任务；改为整数输入输出。

## 第 04 关：贝壳分组

**前置与目标：** K03；学习 K04。讲解 / 产生除法结果、// 求整商、% 求余数。本题仅考虑非负数量和正的每组容量。

**情境：**上一关，在你的帮助下， Ottly 的小摊的生意越来越好。

攒了一整季的贝壳之后，她打算把它们分装成小袋送给海滩上的每一位朋友。
她买的袋子每只只能装固定颗数。装到最后总会剩下几颗，怎么都凑不满一袋。

于是她需要两个答案：
1.能装满几袋？
2.装完之后还剩几颗？

**知识点讲解：**
1. 三种除法

普通除法：带小数点的结果，例如 17除以5=3.4。
整除：只要整数部分，例如 17//5=3，余2舍去。
取余：除完之后剩下的，例如 17%5=2，这里得到的结果是 17整除5 得到的余数。

2. 为什么不能用普通除法
普通除法会得到带小数点的数。可是 Ottly 没法把袋子装出 0.4 袋来——袋子只能整袋整袋地装。
所以"能装满几袋"要的是整数部分，也就是整除的结果。

3. 整除求能装满几袋
整除的特点是：只要整数部分，把小数点后面全部丢掉。17 除以 5 的整数部分是 3，所以能装满 3 袋。

4. 取余求还剩几颗
取余求的是除完之后剩下来的那一点。17 颗，每 5 颗装一袋，装走 15 颗，还剩 2 颗。
整除和取余是一对搭档：一个告诉你"装走了几整袋"，另一个告诉你"还剩多少"。

5. 一个能自我检查的关系式
这两个结果合起来，应该能还原出原来的总数：
```
袋数 × 每袋数量 + 剩余 = 总数
3 × 5 + 2 = 17  ✓
```

6. 余数一定小于每组数量
如果算出来的余数大于或等于每袋数量，那说明还能再装一袋。

使用整除和取余，输出两行：完整组数、分组后剩余贝壳数。

剩余数量不再组成一组。

**样例：**
输入：
```

```
输出：
```

2
```

**参考解：**

```python

```

特点一：else 后面不写条件。

```
特点二：if 加 else 合起来保证"总有一条路会被走"。 不是走上面那条，就一定走下面那条，不存在两边都不走的情况——因为 else 代表所有剩余可能。

```

elif 星期二
    上午第一节上数学课
elif 星期三
    上午第一节上语文课
else
    上午第一节不上课
```
程序按顺序从上往下走，如果走到elif，说明上一个if的条件不成立。

## 第 06 关：安全出航

```
True    # 真，成立
False   # 假，不成立
它们的首字母必须大写，而且不加引号。
```
例如：
```

```
输出：
```
False
```
```
print(2 <= 2)
```
输出：
```
True
```
```
print("True")
```

```
True —— 但这只是四字母的文字，不是布尔值

2. 比较运算的产物是"结论"，不是"数字"
前几关 + - * // 的结果都是数字。但比较运算的结果是真或假：
```

```
可以把它理解成一句问话的答案：程序问"潮汐等级小于或等于 2 吗？"，Python 回答 True 或 False。

| 写法 | 算出来的东西 |
|---|---|

| 2 <= 3 | 布尔值 True |

3. and：两个都为真，整体才为真

左边	右边	左边 and 右边
True	True	True
True	False	False
False	True	False
False	False	False

回到港湾：tide <= 2 and wind <= 3 的意思是"潮汐合规矩而且风力也合规矩"。缺一条都不行。

4. or 和 not 长什么样（本关仅作了解）

左边	右边	左边 or 右边
True	True	True
True	False	True
False	True	True
False	False	False
not 读作"不"，把真假翻转：
```
not True     # False
not False    # True
not (wind <= 3)   # wind >= 3
```

一张表记住三个词：
| 连接词 | 什么时候整体为真 | 生活里的说法 | 特点 |
|---|---|---|---|
| and | 全部条件都真 | 而且 | 严格 |
| or | 至少一个条件为真 | 或者 | 宽松 |
| not | 原来是假 | 不是 | 翻转 |

## 第 07 关：沿岸数路标

**前置与目标：** K03、K05；学习 K07。先讲循环变量、循环体、range 的起点与不包含的终点。补充 range(n) 从 0 开始，便于以后按次数读取输入。

**情境：**海獭港湾的外海有一片浅滩，涨潮时看不见，退潮时才露出来。獭爸每次带小海獭夜航回来都要沿着浅滩边缘走，光靠月光很容易撞上礁石。

于是港湾交给 Ottly 一个任务：在浅滩边上一根一根地插路标桩，从 1 号编到 n 号，每根桩上钉一块牌子，写着自己的编号。这样夜里只要顺着编号数下去，就能安全靠岸。

请你帮帮Ottly，给路标桩编号吧。

**知识点讲解：**
1. 为什么需要"循环"
现在如果没有循环，要给 3 根桩编号，你得写三行：
```
print(1)
print(2)
print(3)
```
可桩数 n 是输入，写代码的时候你还不知道它到底是多少。

这里有个规律：要做的事完全一样（打印一个编号），只是每次用的数字不同。 凡是"同一件事重复做很多次"，就该交给循环。学循环之前，你只能一遍遍复制代码；学会循环之后，一行代码就能执行 n 次。

2. for 语句的骨架
```
for i in range(1, n + 1):
    print(i)
```
把它拆成四块：
```
for  i  in  range(1, n + 1)  :      ← 第一行：说明"要重复多少次"
     print(i)                        ← 缩进的一行：每次真正做的事
     └──────┬──────┘
        第二部分：循环体
└─┬─┘ └┬┘ └──────┬───────┘
  │    │         └── 第四部分：数数的范围（要数哪些数）
  │    └── 第三部分：循环变量，每一轮换成一个新数字
  └── 第一部分：关键字，读作"对于……中的每一个"
```
| 部分 | 作用 | 注意 |
|---|---|---|
| for | 说明"开始一个重复" | 三个字母都小写；不要写成 For 或 FOR |
| i | 循环变量，每一轮自动换成范围内的下一个数字 | 名字可以随便起，但习惯用 i；不能和 n 重名 |
| in | 读作"在……之中" | 前后各一个空格 |
| range(...) | 数数器，负责依次报出数字 | 括号是英文圆括号 |
| : | 行尾冒号，表示"下面缩进的就是要重复的内容" | 最容易漏的一个符号 |
| 缩进 | 决定哪些行属于循环体 | 用 4 个空格；不缩进的行只在循环结束后执行一次 |

3. range 的使用方法
range 是一个"数数器"，它接收起点和终点，从起点开始一个一个往后数，但永远数不到终点。
```
range(1, 4)     # 依次报出 1、2、3 ——  报不到 4！
终点是开区间：写作 range(起点, 终点)，实际给出的是"起点到终点减一"。
```
|写法|依次报出的数字|一共有几个|
| ---- | ---- | ---- |
|`range(3)`|0, 1, 2|3 个|
|`range(1, 4)`|1, 2, 3|3 个|
|`range(1, 8)`|1, 2, 3, 4, 5, 6, 7|7 个|
|`range(1, 1)`|（什么也不报）|0 个|
|`range(1, 0)`|（什么也不报）|0 个|

由此可以总结两条非常有用的规律：
1.循环次数 = 终点 − 起点。range(1, 8) 的次数是 8 − 1 = 7。
2.想数到 n，终点就要写 n + 1。这才是 range(1, n + 1) 里那个 + 1 的来历——把 n 本身包括进来。

为什么 Python 要这么"别扭"？因为这种"含头不含尾"的写法有两个好处：range(1, 8) 的次数一眼就是 8−1；而且从 0 开始时 range(n) 的次数正好是 n 次。习惯它以后会很方便。

4. range(n) 与 range(1, n + 1) 的区别
写法	报出的数字	适合做什么
range(n)	0, 1, 2, …, n−1	重复 n 次，不关心数字本身（比如"读 n 行输入"）
range(1, n + 1)	1, 2, 3, …, n	数字本身有意义（编号、第几天）
本关要打印的是编号，编号从 1 开始，所以必须用 range(1, n + 1)。如果写成 range(n)，n = 3 时会打印 0 1 2。

后面的关卡里你会经常看到 range(n)，那时它的任务是"把一件事做 n 次"，不是"编号"。

5. 循环变量 i 每一轮都在变
i 就是一个普通变量，只不过它是由 for 每轮自动重新赋值的：

第几轮	i 的值	执行 print(i) 的结果
第 1 轮	1	打印 1
第 2 轮	2	打印 2
第 3 轮	3	打印 3
第 n 轮 n	打印 n，循环结束
所以唯一的那一行 print(i) 被执行了 n 次，每次打印的数字不同。这正是前面"同一件事重复做，只是数字不同"的落地方式。

变量名用 i 只是全世界的习惯（来自 index，索引），你写 for num in range(1, n + 1) 或 for 桩号 in ... 完全正确，只要前后一致。

6. 缩进决定"哪些行被重复"
```
n = int(input())
for i in range(1, n + 1):
    print(i)
```
n = int(input()) 不缩进 → 只执行一次，在循环开始之前。
print(i) 缩进 → 属于循环体，执行 n 次。
如果没有把 print 缩进：
```
n = int(input())
for i in range(1, n + 1):
print(i)          # IndentationError：expected an indented block
```
Python 会直接报错，因为 for 冒号后面必须有一块缩进的循环体，不能是空的。

如果你写了两个 print，一个缩进一个不缩进：
```
for i in range(1, 4):
    print(i)      # 打印 1、2、3（三次）
print("靠岸")      # 只打印一次，在三次之后
```
缩进的重复、不缩进的只做一遍。

7. 特殊情况：n = 0 时"零次循环"
题面说 n 可以是 0（一根桩也不插）。代入 range(1, n + 1)：
```
n = 0  →  range(1, 1)  →  什么数字都不报
```

"循环跑零次"是合法且常见的情况，不是错误。

## 第 08 关：收集贝壳总数

**前置与目标：** K07、K03；学习 K08。重点讲“更新后的总数 = 原总数 + 当前数”，初始化放在循环之前。本关讲解 += 是这一更新的简写，参考解保留完整写法。

**情境：**Ottly 想用贝壳串一串风铃挂在洞口。她每天退潮后去浅滩捡贝壳：第 1 天捡 1 枚，第 2 天捡 2 枚……第 i 天就捡 i 枚，一连攒了 n 天。

`1 + 2 + 3 + 4 + 5 = 15`

可是，如果 Ottly 连续捡了 100 天呢？难道要把 100 个数字一个一个加起来吗？

当然不用！我们可以请 Python 的 **`for` 循环**来帮忙。

2. 认识 for 循环：让重复的事情自动完成

`for` 循环可以让程序重复执行一段代码。

```python

```

这里有两个小知识点：

- **`for i in`**：让变量 `i` 依次取出一组数字。
- **`range(1, n + 1)`**：生成从 1 到 n 的整数序列。注意，`range()` 包含起始数字，但不包含结束数字，所以要写 `n + 1` 才能取到 n。

3. 认识累加：准备一个贝壳小篮子

现在，我们需要一个变量来保存 Ottly 捡到的贝壳总数。

```python
total = 0
```

可以把 `total` 想象成 Ottly 的贝壳小篮子，一开始里面没有贝壳，所以数量为 0。

每过一天，就把当天捡到的贝壳放进篮子里：

```python
total = total + i
```

这行代码的意思是：**把原来篮子里的贝壳数量，加上今天捡到的数量，再保存回 `total`。**

对于本关的整数，`total += i` 是 `total = total + i` 的简写。累加器应在循环前初始化，循环结束后再输出最终总数。

假设 Ottly 捡了 5 天：

| 天数 i | 今天捡到 | 篮子里的贝壳总数 total |

| 第 2 天 | 2 枚 | 1 + 2 = 3 |
| 第 3 天 | 3 枚 | 3 + 3 = 6 |
| 第 4 天 | 4 枚 | 6 + 4 = 10 |
| 第 5 天 | 5 枚 | 10 + 5 = 15 |

瞧！每循环一次，`total` 就会更新一次。等所有天数都计算完，篮子里的贝壳数量就是最终答案。

## 第 09 关：存够小贝壳

**情境：**海獭 Ottly 最近看中了一件漂亮的海底装饰品，她想把它买来装饰自己的家。可是，这件装饰品需要 target 枚贝壳才能换到，而 Ottly 现在一枚贝壳也没有。

**知识点讲解：**

1. 认识 while 循环

之前，我们认识了 `for` 循环，它可以帮助我们完成指定次数的重复操作。
但是，Ottly 这次遇到了一个新问题：她不知道究竟需要存多少天，只知道要一直存到贝壳足够为止。
这时候我们就可以使用 `while` 循环！

```python
while 条件:
    重复执行的代码
```

`while` 的意思是“当……的时候”。
只要循环条件成立，程序就会不断重复执行缩进的代码；当条件不再成立时，循环就会结束。

```

在开始储蓄之前，我们需要准备两个变量：

saved = 0

```

- `saved`：记录 Ottly 已经存下的贝壳数量，初始为 0。
- `days`：记录 Ottly 已经存了多少天，初始也为 0。

3. 每天存入 3 枚贝壳

Ottly 每存一天，就要完成两件事情：

```python

```

第一行表示储蓄罐里的贝壳增加 3 枚，第二行表示存钱的天数增加 1 天。

例如，假设 Ottly 的目标是攒够 10 枚贝壳：

| 0 | 0 | 否 |

| 3 | 9 | 否 |

当 `saved` 达到或超过 `target` 时，`saved < target` 不再成立，循环就会自动结束。

```python
print(days)
```

就可以知道 Ottly 至少需要存多少天啦！

## 第 11 关：温差记录表

**情境：**最近海边的天气忽冷忽热，Ottly 决定连续记录几天的海水温差，看看哪一天的温差最大。

她准备了一本“海边温差记录表”。每天测量完成后，就把当天的温差记录下来。等所有数据都记录完成，她想知道：这段时间里最大的温差是多少？

请你帮助 Ottly 完成温差统计！

第一行输入记录数 n，接下来 n 行每行输入一个温差值。请将这些温差值依次存入一个列表，然后通过 for 循环逐个比较，找出其中的最大值。
不能直接使用 max()，也不能通过排序来寻找最大值。

**知识点讲解：**
1. 用列表保存一组数据

前面的题目中，我们通常只需要使用一个变量保存一个数据。但这一次 Ottly 要记录很多天的温差。如果每个温差都使用一个变量来保存，就会变得非常麻烦。

这时候可以使用 列表（list）。

一个空列表可以这样写：

values = []

[] 表示一个空列表，它就像 Ottly 准备好的一张空白记录表，现在里面还没有任何温差数据。

2. 使用 append() 把数据放进列表

每天测量出一个温差后，可以使用 append() 把它添加到列表末尾：

values.append(5)

执行以后，列表就变成：

[5]

如果再添加 -2 和 8：

values.append(-2)
values.append(8)

列表就变成：

[5, -2, 8]

所以，append() 可以理解成：把一个新的数据添加到列表中。

注意：append() 是直接修改原来的列表，不需要写成：

values = values.append(5)

append 返回 None，赋给 values 会使它不再关联列表，后续列表操作才会报错。只需要直接写：

values.append(5)

除了字符串以外，len() 也可以用来获取列表中有多少个元素。

例如：

values = [5, -2, 8]
print(len(values))

结果是：

3

这里的 3 表示列表中有 3 个温差记录。

4. 使用索引找到列表中的第一个元素

列表中的元素有自己的位置，这个位置叫做索引。

Python 的索引从 0 开始，所以：

values[0]

表示列表中的第一个元素。

例如：

values = [5, -2, 8]
print(values[0])

输出：

5

因为 5 是这张温差记录表中的第一项。

5. 使用 for 遍历列表

列表中的数据也可以直接使用 for 循环逐个取出来：

for value in values:
    print(value)

如果 values 是 [5, -2, 8]，那么 value 就会依次变成：

5 → -2 → 8

这和上一关逐个检查字符串中的字符很像，只不过这一次，我们是在逐个检查列表中的数据。

6. 不使用 max()，自己寻找最大值

现在问题来了：怎样找出所有温差中的最大值？

可以先假设第一个温差就是目前最大的值：

largest = values[0]

为什么选择第一个？

因为题目保证 n 至少为 1，所以列表一定不是空的，values[0] 一定存在。

然后遍历所有温差：

for value in values:
    if value > largest:
        largest = value

每检查到一个新的温差，就把它和目前的 largest 比较。

如果发现：

value > largest

说明找到了一个更大的温差，就更新 largest。

例如温差依次为：

5、-2、8、6

开始时：

largest = 5

检查 -2：-2 不比 5 大，不更新。

检查 8：8 比 5 大，于是：

largest = 8

检查 6：6 不比 8 大，不更新。

最终：

largest = 8

这就是所有记录中的最大温差。

🌟 小结

这一关可以把整个过程想象成 Ottly 翻看自己的温差记录表：

创建空表 → 一条一条记录温差 → 从第一条记录开始比较 → 遇到更大的就更新 → 最后得到最大值。

需要掌握的知识点有：

1.[]：创建空列表。

2.append()：向列表中添加元素。

3.len()：获取列表中元素的数量。

4.values[0]：访问列表中的第一个元素。

5.for value in values：逐个遍历列表中的元素。

6.if value > largest：通过比较不断寻找更大的值。

**任务：**第一行输入记录数 n（至少为 1），接下来 n 行每行输入一个整数温差值，可以为负。请将这些温差值依次存入一个列表，然后通过 for 循环逐个比较，找出其中的最大值。

## 第 12 关：封装达标统计器

**前置与目标：** K05、K08、K11；学习 K12。先独立讲解 def、形参/实参、调用、return 与局部变量。明确 return 交回结果并结束本次调用，print 只显示内容。此关综合已学知识，不加入新容器或算法。

**情境：**海边一年一度的“小海獭潜水挑战赛”开始啦！

Ottly 负责记录每只小海獭的比赛成绩。比赛结束后，她需要统计出：有多少只小海獭的成绩达到了规定的达标线？

比如，达标线是 60 分，如果成绩是 55、72、60、48、91，那么达到 60 分或以上的成绩有 3 个。

Ottly 发现，以后每次比赛都可能需要进行这样的统计。与其每次都重新写一遍代码，不如把“统计达标人数”这个功能封装起来，做成一个可以重复使用的达标统计器！

请你帮助 Ottly 实现：count_at_least(scores, threshold)

这个函数接收一组成绩和一个达标线，返回达到或超过达标线的成绩数量。

**知识点讲解：**
1. 为什么要使用函数？

如果我们经常需要完成某一项任务，可以把完成这个任务的代码整理起来，给它取一个名字。

在 Python 中，可以使用 def 定义函数：

def 函数名():
    要执行的代码

例如：

def say_hello():
    print("Hello!")

这样，我们就创建了一个叫 say_hello 的函数。

以后想执行这段代码时，只需要调用它：

say_hello()

函数就像 Ottly 制作的一个“小工具”。工具做好以后，需要使用时直接拿出来即可，不需要每次重新制作。

2. 使用参数告诉函数要处理什么

我们的达标统计器需要知道两件事情：

要统计哪些成绩。

达标线是多少。

因此，可以在定义函数时给它设置两个形参：

def count_at_least(scores, threshold):

这里：

scores 是成绩列表。

threshold 是达标分数线。

函数定义中的 scores 和 threshold 就叫做形参，可以把它们理解成函数预留出来的两个“入口”。

真正调用函数时，我们需要把实际的数据传进去：

count_at_least(scores, threshold)

这里传入的 scores 和 threshold 就是实参。

简单来说：

形参是函数定义时写的名字，实参是调用函数时真正传进去的数据。

3. 函数内部可以使用自己的局部变量

函数内部可以创建变量：

count = 0

这个 count 只负责记录当前函数执行过程中有多少个成绩达标。

这种只在函数内部使用的变量叫做局部变量。

接下来，我们可以使用之前学习过的 for 和 if：

for score in scores:
    if score >= threshold:
        count = count + 1

程序会逐个检查成绩。

如果当前成绩 score 大于或等于 threshold，就说明这名选手达标，count 增加 1。

4. return：把计算结果交给函数外面

统计完成以后，我们需要把 count 的结果交出去。

这时候要使用：

return count

return 的作用是：把结果返回给调用函数的地方，并结束本次函数调用。

例如：

def add(a, b):
    result = a + b
    return result

调用：

answer = add(3, 5)

函数计算出 8 后，通过 return 把 8 交给 answer。

所以：

函数内部计算 → return 结果 → 函数外部接收结果

5. return 和 print 不一样

这里特别要注意：

print(count)

和：

return count

并不是一回事。

print() 的作用是把内容显示出来。

return 的作用是把结果交还给调用函数的地方。

例如：

def test():
    return 10

我们可以这样使用：

x = test()
print(x)

这里 10 被函数返回，然后交给变量 x。

而如果函数写成：

def test():
    print(10)

它只是把 10 显示在屏幕上，并没有把 10 作为函数结果返回。

所以这道题要求函数“返回整数”，就必须使用：

return count

而不能用 print(count) 代替。

6. 把前面学过的知识组合起来

现在，我们已经有了制作“达标统计器”所需要的所有知识：

def count_at_least(scores, threshold):
    count = 0
    for score in scores:
        if score >= threshold:
            count = count + 1
    return count

这里没有新的算法。

它实际上是把之前学过的知识组合起来：

def：定义函数。

参数：告诉函数需要处理哪些数据。

count = 0：使用变量进行计数。

for：逐个遍历成绩。

if：判断成绩是否达标。

>=：判断成绩是否大于或等于达标线。

return：将最终统计结果交给函数外部。

最后，在函数外读取数据并调用函数：

print(count_at_least(scores, threshold))

函数会返回达标数量，外面的 print() 再把这个结果显示出来。
