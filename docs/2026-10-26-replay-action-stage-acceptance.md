# 代码回放动作演示增强版验收

## 已实现

- 桌面三栏：代码、刚完成的动作、当前变量及累积输出。当前代码行仍采用“执行前”快照，动作明确标注刚完成的行；程序结束时高亮最后已完成位置。
- 第2关：直接 input() 的实际读取内容进入变量；单参数 print 中可确认的字符串加法展示各部分、结果和新增输出。执行打印前不显示未来输出，退回上一步后同步恢复。
- 第8关：整数加法展示实际操作数与结果；赋值覆盖展示旧值替换成新值，采用不同颜色，但不据此判错。展示实际进入循环体的轮次。
- 其余正式关卡使用同一个动作组件，函数进入/返回、异常和真实前后变化都有通用视图；原第11关列表格子保留。条件不猜真假，复杂表达式回退真实状态变化。
- AI继续点击才调用现有DeepSeek服务，默认显示第一句，完整解释可展开；未请求时显示程序生成的观察提示，不冒充AI回答。
- 播放器固定可见，输入设置折叠；长代码、动作和输出局部滚动。窄屏上下排列，遵循系统减少动态效果偏好。

## 支持范围与限制

- 动作是已完成的相邻执行快照信息，不重新执行程序。跨函数间隙只显示实际变化，输出增量按全局时间顺序比较，变量按作用域比较。
- 精细表达式仅支持受限的整数/文字常量、变量、加法/拼接及单参数默认print；直接input无提示语。减乘除、格式化、动态下标、复杂调用等仍可回放，但不承诺展开算式。
- 循环轮次指同次进入循环期间、当前循环自身的实际轮次；嵌套循环在重新进入时重置内层计数。
- 语法错误、超时、轨迹截断保留原提示，缺少可信动作时不会补造动画或输出。AI服务不可用仍可步进。
- 本轮没有扩展加练题回放，没有训练模型，也没有改判题或数据库结构。代码未提交或推送。
