# Ottly 12 关知识点汇总

本文汇总当前正式主线 12 个关卡的知识点，供项目介绍、开发对接、演示和复习使用。内容以 `backend/app/data/levels.json`、`knowledge.json` 以及各关题目 JSON 为准。

> `backend/app/data/level2.json` 是旧版“1 到 100 求和”练习，仅用于兼容历史复习记录，不属于当前正式第 2 关。当前第 2 关是 `greeting-v1`。

课程按“基础输出 → 输入和运算 → 判断 → 循环 → 字符串和列表 → 函数”的顺序推进。每关主要引入一个新知识组，并通过前置关卡保证学生先学习所需基础。

## 二、各关知识点介绍

### 第 1 关：初识小海獭

- **知识点：** K01 字符串与输出
- **学习目标：** 学会使用 `print()` 输出字符串，认识括号、引号和空格，理解“程序代码”和“程序输出”的区别。
- **本关任务：** 精确输出 `Hello, World!`。
- **需要注意：** 大小写、逗号、空格和感叹号都属于输出内容，必须与要求一致。
- **常见错误：** 漏写引号或括号、使用中文标点、输出多余提示文字、大小写不一致。
- **题目文件：** `backend/app/data/level1.json`

### 第 2 关：打招呼

- **知识点：** K02 变量、输入与字符串拼接
- **学习目标：** 理解变量赋值，使用 `input()` 读取一行文字，并把固定字符串与变量内容拼接起来。
- **本关任务：** 读取姓名并输出 `Hello, 姓名!`。
- **需要注意：** `input()` 得到的是字符串；要保留姓名原来的大小写和内部空格；逗号后只有一个空格。
- **常见错误：** 没有保存输入、变量先使用后赋值、拼接时漏掉空格或感叹号、输出输入提示语。
- **题目文件：** `backend/app/data/greeting-v1.json`

### 第 3 关：贝壳小商店

- **知识点：** K03 整数输入与算术运算
- **学习目标：** 使用 `int()` 把输入转换为整数，完成乘法和减法，并把计算结果保存到变量中。
- **本关任务：** 根据单价、数量和支付金额计算总价及差额。
- **需要注意：** `input()` 默认得到字符串，参与算术运算前需要转换；支付不足时差额可以是负数。
- **常见错误：** 忘记 `int()`、把乘法写成加法、减法顺序颠倒、输出单位或说明文字。
- **题目文件：** `backend/app/data/shell-shop-v1.json`

### 第 4 关：贝壳分组

- **知识点：** K04 整除与取余
- **学习目标：** 区分普通除法 `/`、整除 `//` 和取余 `%`，理解商和余数分别表示什么。
- **本关任务：** 计算能装满的袋数和剩余贝壳数。
- **需要注意：** 剩余贝壳不能算成完整的一袋；每袋容量不会为零。
- **常见错误：** 使用 `/` 得到小数、混淆 `//` 和 `%`、把剩余部分向上算成一袋。
- **题目文件：** `backend/app/data/shell-groups-v1.json`

### 第 5 关：领取徽章

- **知识点：** K05 比较与条件分支
- **学习目标：** 使用比较运算以及 `if`、`elif`、`else`，根据互斥的分数区间选择一个结果。
- **本关任务：** 根据分数输出 `GOLD`、`SILVER` 或 `TRY_AGAIN`。
- **需要注意：** 60 和 90 等边界值必须归入正确区间；条件分支需要正确缩进。
- **常见错误：** 使用错误的 `<` 或 `<=`、遗漏边界值、多个分支同时成立、缩进错误。
- **题目文件：** `backend/app/data/badge-v1.json`

### 第 6 关：安全出航

- **知识点：** K06 布尔值与逻辑运算
- **学习目标：** 理解条件结果的真假，使用 `and`、`or`、`not` 组合多个条件。
- **本关任务：** 只有潮汐和风力都满足安全条件时输出 `YES`。
- **需要注意：** 本题要求两个条件同时成立，因此核心逻辑是 `and`。
- **常见错误：** 把 `and` 写成 `or`、比较符号方向错误、忽略“都满足”的要求。
- **题目文件：** `backend/app/data/safe-sailing-v1.json`

### 第 7 关：沿岸数路标

- **知识点：** K07 `for` 循环与 `range`
- **学习目标：** 理解循环变量和循环体，使用 `for` 重复执行代码，掌握 `range` 右端不包含的特点。
- **本关任务：** 依次输出 1 到 `n`，每个数字单独一行。
- **需要注意：** 要包含 `n`，通常需要让 `range` 的结束值写到 `n + 1`；`n` 为 0 时不输出内容。
- **常见错误：** 少输出最后一个数、从 0 开始、多输出一次、把 `print()` 放到循环外。
- **题目文件：** `backend/app/data/coastal-markers-v1.json`

### 第 8 关：收集贝壳总数

- **知识点：** K08 累加器与变量更新
- **学习目标：** 在循环前初始化总数，在循环内把当前值加入原总数，理解变量更新会保留此前的累计结果。
- **本关任务：** 使用 `for` 循环计算 1 到 `n` 的总和。
- **需要注意：** 总数应在循环前初始化；循环中需要执行“旧总数加当前值”；最后只输出一次总和。
- **常见错误：** 每轮用当前值覆盖总数、把初始化写进循环、漏掉最后一个数、在循环中输出所有中间结果。
- **题目文件：** `backend/app/data/shell-total-v1.json`

### 第 9 关：存够小贝壳

- **知识点：** K09 `while` 循环与终止
- **学习目标：** 根据条件决定是否继续循环，在每轮推进状态，并保证循环最终能够结束。
- **本关任务：** 每天存入 3 枚贝壳，计算达到目标所需的最少天数。
- **需要注意：** 循环条件应表达“还没有达到目标”；贝壳数和天数都需要在循环中更新；目标为 0 时答案为 0。
- **常见错误：** 状态没有更新造成死循环、条件方向相反、刚好达到目标时多循环一次、忽略零目标。
- **题目文件：** `backend/app/data/shell-savings-v1.json`

### 第 10 关：Ottly 的海边电台

- **知识点：** K10 字符串遍历与条件计数
- **学习目标：** 使用 `len()` 获取字符串长度，逐个遍历字符，并在满足条件时更新计数器。
- **本关任务：** 输出文本长度以及指定字符出现的次数。
- **需要注意：** 字符比较区分大小写；空格也属于字符；统计变量需要正确初始化和更新。
- **常见错误：** 忽略空格、擅自转换大小写、每轮覆盖计数器、统计了不同的字符。
- **题目文件：** `backend/app/data/radio-text-v1.json`

### 第 11 关：温差记录表

- **知识点：** K11 列表与遍历
- **学习目标：** 创建列表，使用 `append()` 保存数据，通过索引或循环访问元素，并在遍历中跟踪最大值。
- **本关任务：** 保存输入的温差数据，使用 `for` 比较并输出最大值。
- **需要注意：** 温差可能是负数，最大值不能简单初始化为 0；本关不能使用 `max()` 或排序寻找答案。
- **常见错误：** 没有把数据加入列表、最大值固定从 0 开始、比较方向错误、输出列表而不是最大值。
- **题目文件：** `backend/app/data/temperature-max-v1.json`

### 第 12 关：封装达标统计器

- **知识点：** K12 函数与返回值
- **学习目标：** 定义和调用函数，理解参数、局部变量与 `return`，让函数根据输入计算并返回结果。
- **本关任务：** 完成 `count_at_least(scores, threshold)`，返回大于或等于阈值的成绩数量。
- **需要注意：** 返回值必须是整数；每次调用都要重新计数；不能修改传入的列表；空列表应返回 0。
- **常见错误：** 使用 `print()` 代替 `return`、遗漏等于阈值的情况、把计数变量放在函数外、修改原列表、重复调用时沿用旧结果。
- **题目文件：** `backend/app/data/count-at-least-v1.json`

## 三、知识点之间的关系

```text
K01 输出
  ↓
K02 输入、变量和字符串
  ↓
K03 整数与算术
  ↓
K04 整除和取余
  ↓
K05 条件分支 → K06 逻辑运算
  ↓
K07 for 循环 → K08 累加器 → K09 while 循环
  ↓
K10 字符串遍历 → K11 列表遍历
  ↓
K12 函数与返回值
```

其中 K07、K08 和 K09 都涉及循环，但训练重点不同：

- K07 关注循环次数、循环范围和 `range` 边界；
- K08 关注循环过程中如何保留并更新累计结果；
- K09 关注循环条件、状态推进和正常终止。
