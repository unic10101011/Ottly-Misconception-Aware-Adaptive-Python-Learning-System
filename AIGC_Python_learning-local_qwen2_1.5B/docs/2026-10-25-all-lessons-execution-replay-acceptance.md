## 执行限制

教学子集支持基本数值、字符串、条件、循环；11/12关额外支持一维列表、append、索引和顶层普通位置参数函数。仍拒绝导入、任意属性/方法、嵌套函数、装饰器、复杂签名、关键字参数、嵌套容器和动态代码。超出范围显示说明，不伪造执行过程。第8关保留原整数子集与n=0～100。

代码最多6000字符、AST最多500节点、最多300步、输出6000字符、文本2000字符、一维列表100项、调用深度16。单行多语句拒绝；列表重复和字符串重复在分配前检查。字符串索引和字符遍历得到的字符仍保留长度限制。父进程3秒超时，Linux另有CPU和内存上限；达到限制标记轨迹不完整。不是完整Python执行器。
