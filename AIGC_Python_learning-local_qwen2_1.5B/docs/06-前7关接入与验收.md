## 每关的完整流程

1. 阅读情境、可折叠的知识讲解、任务和样例；第 1 关无需输入，第 7 关的零次循环样例明确标记无输出。
2. 编写代码。代码和运行输入继续按账号、题号保存到当前浏览器，离开和刷新后恢复。
3. 点击运行，固定输出区展示本次结果；运行不创建正式提交，也不解锁关卡。
4. 点击提交，后端执行正式测试并保存判题、题目版本、难度及知识点快照。隐藏测试仅展示通过状态。
5. 失败后按需逐级查看三级提示，并记录查看进度；可到我的错题复习。
6. 通关后保留进度，允许获取参考解及逐步解析，提供下一关入口；未经通关的参考解仍由后端拒绝。

模型、参数、提示词和生成审核流程没有改动。`lesson_feedback.py` 在接口外层为活跃关卡提供基础提示回退，已合格的模型分析保持原样。固定提示标记 `source=fixed`、`model=null`，知识点使用字典名称并映射为编号。语法及未定义变量使用原有通用提示；其他情况使用本关配置。没有可用公开证据时不构造提示，不引用隐藏输出，也不把未采集输出伪装成空输出。

## 内容校对与测试边界

同步修正教学原稿中 print 字母数、问候语双空格展示、徽章区间和分支冒号、not 的等价条件、整除的适用范围、循环变量命名及 range 次数公式等明确错误。

第 3 关原稿没有保证支付金额足够，按原参考解保留“支付金额减总价”的结果，金额不足时允许负数，并增加对应测试。第 7 关零次循环样例作为公开测试，另测单次循环和正常多次循环。

当前判题检查输入输出结果，**不执行语法树检查以强制某种写法**。例如第 7 关教学要求使用 for，但输出正确的其他算法也可能通过；是否强制语法结构需另行确定。
