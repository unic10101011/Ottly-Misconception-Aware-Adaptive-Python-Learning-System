## 第 01 关：初识小海獭

**前置与目标：** 无编程前置；学会 K01。先解释英文括号、成对引号以及空格也是字符。

**情境：** 浪花把一只小海獭冲上了沙滩，她叫 Ottly。

Ottly 还不会说人类的语言，她只会用你的程序说话——屏幕上打出什么，她就说什么。

在编程世界里，每一个新朋友开口说的第一句话都是一样的。这是从 1972 年流传下来的老规矩，几十年来所有学编程的人都从这一句开始。

现在轮到你了。帮 Ottly 说出她在人类世界的第一句话。

**知识点讲解：**
1. 代码和输出
你可以这样想：你对 Ottly 说"请念出 Hello, World!"。她会念"Hello, World!"，不会把"请念出"三个字也念出来。

2. print 这条指令的三个部分
```
print("Hello, World!")
└─┬─┘└──────┬──────┘
  │         └── 第三部分：要念出来的内容
  └── 第一部分：函数的名字
     └─ 第二部分：一对英文圆括号，是"喂给它东西"的入口
```
| 部分 | 作用 | 注意 |
| print | 函数的名字，可以理解为 Ottly 的嘴巴 | 四个字母都是小写 |
| ( ) | 英文圆括号，把要念的东西括起来 | 必须是英文半角，而且必须成对 |
| "Hello, World" | 要念出来的内容 | 必须用引号包住 |

```
SyntaxError: invalid character '（' (U+FF08)
这个报错的意思是："我在这行里看到了一个我不认识的字符。" U+FF08 就是中文全角左括号的编号。
```

3. 空格也是一个真实的字符
空格不是"没有东西"。它是一个字符，和字母一样占一个位置，一样会被逐字比较。

4. print 会自动换行
print 每次执行完，自动跳到下一行。所以你不需要自己写换行符——只要正确地写完这一句，回车就自动加上了。

本关只需要输出一行，所以你只要写一条 print。

**任务：**不需要任何输入。 用 print 输出一行：
```
Hello, World!
```

**参考解：**

```python
print("Hello, World!")
```

**三级提示：** L1：我们想让 Python 显示一段文字，它怎么知道这段文字从哪里开始、到哪里结束？L2：看第 1 行 print 后面的那对圆括号，里面的文字有没有被引号包住？再确认引号是英文的还是中文的。L3：请把要显示的文字用一对英文引号包起来，然后对照题面逐字检查大小写、逗号和感叹号，再提交。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `""` | `"Hello, World!\n"` | 精确输出 |

来源关联：futurecoder 字符串基础；保留本项目现有入门任务。

## 第 02 关：打招呼

**前置与目标：** K01；学习 K02。先讲赋值“先算右侧，再把结果交给左侧名字”，再讲 input 返回一行文本，以及字符串用 + 拼接。print 多个参数默认以一个空格分隔。

**情境：** 上一关，Ottly 学会了她人生中第一句话。可是她很快发现一个问题：

那句话是固定的。 不管谁来，她说的都是"Hello, world"。

现在她想向朋友们问好——第一位朋友叫 Ottly，第二位叫 Amy，第三位叫 Sea Otter……Ottly 想让每一位朋友都听到自己的名字。

**知识点讲解：**
1. 变量 = 一个贴了标签的盒子
变量不是"名字"，是一个装东西的盒子，盒子上贴着标签便于你找到它。

赋值：先算右边，再把结果放进左边的盒子。右边的先发生，左边后发生。
取值：写出盒子的标签，得到的是盒子里的内容。

2. 为什么变量名不能加引号？
| 写法 | 含义 |
| name | 盒子里的内容（朋友真正的名字）|
| "name" | 四个固定字母 n-a-m-e |
加了引号，就从"取盒子里的东西"变成了"一段固定文本"。

3. 那个空格是从哪来的？
输出里的 Hello, Ottly! 中间有一个空格。它可能来自两个地方，而这两种写法看起来一样、实际不同：

来自两个输出项之间：打印时自动插入一个空格
来自字符串末尾：你自己在引号里多写了一个空格
如果你两个都用了，就会出现两个空格 → Hello, Ottly!。

4. 变量必须先装东西，才能取
代码是从上往下执行的。如果打印写在读取输入之前，盒子里还是空的，程序会直接报错。

**任务：**输入一行姓名（1–20 个字符，不含首尾空格，可以含内部空格）。

把输入保存到一个变量里，然后输出：
```
Hello, 姓名!
```
**样例：**
| 输入 | 输出 |
|---|---|
| Ottly | Hello, Ottly! |
| Tim | Hello, Tim! |

**参考解：**

```python
name = input()
print("Hello,", name + "!")
```

**三级提示：** L1：问候语中哪部分会随输入变化？L2：查看变量是否真正接收了输入，打印时有没有把变量名加上引号。L3：把输出分成固定前缀、姓名和标点三部分，检查连接处的空格。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"Ottly\n"` | `"Hello, Ottly!\n"` | 基本姓名 |
| 隐藏 | `"Amy\n"` | `"Hello, Amy!\n"` | 防止固定姓名 |
| 隐藏 | `"Sea Otter\n"` | `"Hello, Sea Otter!\n"` | 内部空格 |
| 隐藏 | `"小海獭\n"` | `"Hello, 小海獭!\n"` | 中文文本 |

来源关联：futurecoder 变量与字符串章节；姓名牌题面自编。

## 第 03 关：贝壳小商店

**前置与目标：** K02；学习 K03。先用短示例对比字符串相加和整数相加，再讲 int、+、-、* 和运算优先级。本题只需乘法与减法。

**情境：**上一关，Ottly 学会了向每个朋友打招呼。

现在她在海边支起一个小摊，卖自己捡来又打磨过的贝壳。生意出乎意料地好——麻烦也跟着来了：

顾客说"我要 3 个"，她掰着手指头还勉强算得清；可有人一口气要 100 个，她就彻底算不清了；而且每位顾客都会掏出一把钱让她找零。先算这次要收多少，再算该找回多少，两步都不能错。
Ottly 把最难的三件事交给你：
1.每件卖多少钱
2.顾客要买几件
3.顾客一共带了多少钱

**知识点讲解：**
1. 数字与文字的区别

Ottly 报价 4，你的程序收到的其实是文字 "4"——一个字符，而不是可以计算的数字 4。上一关装名字的盒子，这一关要装数字，就得先把文字"翻译"过来。

2. 文字相加和数字相加，结果完全不同
先看一个例子：

| 写法 | 结果 | 发生了什么 |
|---|---|---|
| 文字相加‘4’+‘3’ | 43 | 两个字符首尾接在一起 |
| 数字相加4+3 | 7 | 真正的算术加法 |
同样是加号，两边是文字就是"拼接"，两边是数字才是"计算"。

3. 用 int 把文字翻译成整数
int 的作用就是把取到的文字变成真正的整数。转换要发生在计算之前，否则后面得到的都是错误答案。

4. 乘法求总价，减法求剩余
总价：每件价格都一样，买若干件就是重复若干次 → 用乘法
找零：顾客带的总钱数，减去这次要付的 → 用减法

**任务：**依次输入单价 price（1–100）、数量 quantity（0–100）和支付金额 budget（0–10000）。

输出：总价、找零，均为整数，不附单位。

**样例：**
输入：（第一行代表单价，第二行代表数量，第三行代表支付金额）
```
4
3
20
```
输出：（第一行代表总价，第二行代表找零）
```
12
8
```

**参考解：**

```python
price = int(input())
quantity = int(input())
budget = int(input())
cost = price * quantity
remaining = budget - cost
print(cost)
print(remaining)
```

**三级提示：** L1：每位顾客买走好几件，Ottly 该怎么算出这一次要收多少钱？L2：看读取三行输入的地方有没有把文字转成整数，再看算总价那一行用的是乘法还是加法。L3：请先把总价算出来存进一个变量，再用支付金额减掉它；最后按任务要求一行一行输出。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"4\n3\n20\n"` | `"12\n8\n"` | 普通购买 |
| 隐藏 | `"7\n0\n10\n"` | `"0\n10\n"` | 数量为零 |
| 隐藏 | `"5\n4\n20\n"` | `"20\n0\n"` | 预算恰好用完 |
| 隐藏 | `"100\n100\n10000\n"` | `"10000\n0\n"` | 范围上限 |

来源关联：Currency Exchange 的乘法总额与余额任务；改为整数输入输出。

## 第 04 关：贝壳分组

**前置与目标：** K03；学习 K04。讲解 / 产生除法结果、// 求整商、% 求余数。本题仅考虑非负数量和正的每组容量。

**情境：**上一关，在你的帮助下， Ottly 的小摊的生意越来越好。

攒了一整季的贝壳之后，她打算把它们分装成小袋，送给海滩上的每一位朋友。

问题来了：她买的袋子每只只能装固定颗数。装到最后，总会剩下几颗，怎么都凑不满一袋。

于是她需要两个答案：
1.能装满几袋？
2.装完之后还剩几颗？

**知识点讲解：**
1. 三种除法

普通除法：带小数点的结果，例如 17除以5=3.4。
整除：只要整数部分，例如 17//5=3，余2舍去。
取余：除完之后剩下的，例如 17%5=2，这里得到的结果是 17整除5 得到的余数。

2. 为什么不能用普通除法
普通除法会得到带小数点的数。可是 Ottly 没法把袋子装出 0.4 袋来——袋子只能整袋整袋地装。
所以"能装满几袋"要的是整数部分，也就是整除的结果。

3. 整除求能装满几袋
整除的特点是：只要整数部分，把小数点后面全部丢掉。17 除以 5 的整数部分是 3，所以能装满 3 袋。

4. 取余求还剩几颗
取余求的是除完之后剩下来的那一点。17 颗，每 5 颗装一袋，装走 15 颗，还剩 2 颗。
整除和取余是一对搭档：一个告诉你"装走了几整袋"，另一个告诉你"还剩多少"。

5. 一个能自我检查的关系式
这两个结果合起来，应该能还原出原来的总数：
```
袋数 × 每袋数量 + 剩余 = 总数
3 × 5 + 2 = 17  ✓
```

6. 余数一定小于每组数量
如果算出来的余数大于或等于每袋数量，那说明还能再装一袋。

**任务：**第一行输入贝壳数量 n（0–10000），第二行输入每袋要装的贝壳数量 k（1–100）。

使用整除和取余，输出两行：完整组数、分组后剩余贝壳数。

剩余数量不再组成一组。

**样例：**
输入：
```
17
5
```
输出：
```
3
2
```

**参考解：**

```python
n = int(input())
k = int(input())
groups = n // k
left = n % k
print(groups)
print(left)
```

**三级提示：** L1：能装满几袋和还剩几颗，这两个问题是同一件事吗？L2：看算组数和算剩余的那两行分别用了什么运算符，再拿样例里的 17 和 5 对一遍。L3：请用 17 和 5 手工算一遍：装满 3 袋，剩 2 颗。再用组数乘每组数量加剩余，看能不能还原出 17。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"17\n5\n"` | `"3\n2\n"` | 有余数 |
| 隐藏 | `"20\n5\n"` | `"4\n0\n"` | 整除 |
| 隐藏 | `"3\n5\n"` | `"0\n3\n"` | 不足一组 |
| 隐藏 | `"0\n1\n"` | `"0\n0\n"` | 零数量 |

## 第 05 关：领取徽章

**前置与目标：** K03；学习 K05。先讲 ==、!=、<、<=、>、>= 和真假结果，区分赋值 = 与比较 ==；再讲分支顺序、冒号、缩进。

**情境：**海滩运动会结束了，Ottly 担任徽章的小裁判。

她需要把金牌、银牌颁给获奖的选手们。

每来一位选手，她要先确认分数，然后把奖颁给这位选手，每位选手只能拿一次奖。

90（含90）~100（含100）分的选手拿金牌；60（含60）~89分的选手拿银牌；60分以下的选手未获奖。

请你来帮帮她吧~

**知识点讲解：**
1. 比较运算给出真假结果
前面几关里，运算的结果都是数字。这一关不一样了——比较运算的结果是"真"或"假"。
它是一个结论：成立就是真，不成立就是假。

1. 六种比较运算符
| 写法 | 含义 |
|---|---|
| == | 等于 |
| != | 不等于 |
| < | 小于 |
| <= | 小于或等于 |
| > | 大于 |
| >= | 大于或等于 |

1. 赋值与比较的区别

| 写法 | 含义 |
| = | 把右边的值赋给左边的变量 |
| == | 判断两边是否相等 |

4. if分支
if 是一个"要不要做"的开关。比如：如果下雨了，我们需要带伞，在代码中可以这样表述：
```
if  下雨:
    带伞
```
if后接的是条件，如果条件成立，就做下一行的事；如果条件不成立，就不做下一行的事。例如 Ottly 确认某位选手的分数在80（含80）~90分之间，那么她就把银牌颁给这位选手，不把金牌颁给这位选手。

5. if-else结构
它代表"做这个，否则做那个"：例如分数大于60代表及格，其他情况代表不及格。
```
if 分数 >= 60:
    print("及格")
else:
    print("不及格")
```
else 的意思是"其他所有情况"。它有两个特点：
特点一：else 后面不写条件。
```
else:                    # 正确
else 分数 < 60:           # 错误，else 不接受条件
```
特点二：if 加 else 合起来保证"总有一条路会被走"。 不是走上面那条，就一定走下面那条，不存在两边都不走的情况——因为 else 代表所有剩余可能。

6. if-elif结构
当选择不止两种，比如要分成金牌、银牌、铜牌、未获奖三档，就需要 elif。
elif 是 else if 的缩写，意思是"否则，如果……"。例如
```
if 星期一
    上午第一节上英语课
elif 星期二
    上午第一节上数学课
elif 星期三
    上午第一节上语文课
else
    上午第一节不上课
```
程序按顺序从上往下走，如果走到elif，说明上一个if的条件不成立。

7. 缩进决定谁属于这条分支
缩进的部分才属于这个分支。 如果打印没有缩进，它就不在任何分支里面，会被无条件执行。

输入整数得分 score（0–100）。

90–100 输出 GOLD
60–89 输出 SILVER
0–59 输出 TRY_AGAIN
使用 if / elif / else，只输出一行。

**样例：**
输入：
```
75
```
输出：
```
SILVER
```

**参考解：**

```python

if score >= 90:
```

## 第 06 关：安全出航

**前置与目标：** K05；学习 K06。先用真假表讲 and 要求两项都真，or 要求至少一项真，not 取反；主线重点检查 and，or/not 可在预测输出练习巩固。

**情境：**浪花退去，Ottly 成了海獭港湾的小小值班员。

每天清晨，大海獭都要划着海藻筏，带小海獭们出海捞贝壳。可港湾的老规矩写得清清楚楚：潮水太满会把筏子顶到礁石上，风太大又根本划不动，所以每次出海前必须先看两块牌子——

潮汐等级 tide 不超过 2（tide <= 2）才安全；
风力等级 wind 不超过 3（wind <= 3）才安全。
两条都合规矩，Ottly 就挂绿旗（屏幕上打出 YES），大家出发；只要有一条不合规矩，就挂红旗（打出 NO），全体留在港湾里休息。

Ottly 想「同时」观察潮汐和风力，就要靠你的程序替她把两个条件绑在一起判断。

**知识点讲解：**
1. 第三种数据类型：布尔值（bool）
前面几关你见过装数字的 int 和装文字的 str。这一关出现第三种数据类型：布尔值，只有两个取值：
```
True    # 真，成立
False   # 假，不成立
它们的首字母必须大写，而且不加引号。
```
例如：
```
print(3 > 5)
```
输出：
```
False
```
```
print(2 <= 2)
```
输出：
```
True
```
```
print("True")
```
输出：
```
True —— 但这只是四字母的文字，不是布尔值
```
小陷阱：True 和 "True" 长得像、意思完全不同。前者是"结论：成立"，后者只是英文单词True。

2. 比较运算的产物是"结论"，不是"数字"
前几关 + - * // 的结果都是数字。但比较运算的结果是真或假：
```
tide = 2
tide <= 2        # 得到 True，不是得到 2
```
可以把它理解成一句问话的答案：程序问"潮汐等级小于或等于 2 吗？"，Python 回答 True 或 False。

| 写法 | 算出来的东西 |
|---|---|
| 2 + 3 | 数字 5 |
| 2 <= 3 | 布尔值 True |

3. and：两个都为真，整体才为真
and 读作"而且"。它的完整真假表只有四行：

左边	右边	左边 and 右边
True	True	True
True	False	False
False	True	False
False	False	False

回到港湾：tide <= 2 and wind <= 3 的意思是"潮汐合规矩而且风力也合规矩"。缺一条都不行。

4. or 和 not 长什么样（本关仅作了解）
or 读作"或者"，只要有一项为真就为真——比较宽松：

左边	右边	左边 or 右边
True	True	True
True	False	True
False	True	True
False	False	False
not 读作"不"，把真假翻转：
```
not True     # False
not False    # True
not (wind <= 3)   # wind >= 3
```

一张表记住三个词：
| 连接词 | 什么时候整体为真 | 生活里的说法 | 特点 |
|---|---|---|---|
| and | 全部条件都真 | 而且 | 严格 |
| or | 至少一个条件为真 | 或者 | 宽松 |
| not | 原来是假 | 不是 | 翻转 |

5. 运算顺序
一行里有好几个符号时，Python 按固定的顺序算：
```
比较运算（<= < > == !=）  →  not  →  and  →  or
```
所以在 tide <= 2 and wind <= 3 里，两个 <= 会先各自算出一个布尔值，and 最后才把两个结果合起来。正确顺序是：
( tide <= 2 )  and  ( wind <= 3 )

输入：
```
2
3
```
输出：
```
YES
```

**参考解：**

```python
tide = int(input())
wind = int(input())
if tide <= 2 and wind <= 3:
    print("YES")
else:
    print("NO")
```

**三级提示：** L1：港湾允许"只满足其中一项"就出海吗？L2：分别算一算 tide <= 2 和 wind <= 3 各自是真是假，特别看一真一假的那两种组合；再看看 2 和 3 这两个数字有没有被等号包含进去。L3：请写成一行的形式：if 条件一 and 条件二:，两个条件都写成"变量 运算符 数字"，确认中间用 and 而不是 or，运算符用的是 <= 而不是 <，然后检查两个 print 有没有缩进、冒号有没有漏。

## 第 07 关：沿岸数路标

**前置与目标：** K03、K05；学习 K07。先讲循环变量、循环体、range 的起点与不包含的终点。补充 range(n) 从 0 开始，便于以后按次数读取输入。

**情境：**海獭港湾的外海有一片浅滩，涨潮时看不见，退潮时才露出来。獭爸每次带小海獭夜航回来，都要沿着浅滩边缘走，光靠月光很容易撞上礁石。

于是港湾交给 Ottly 一个任务：在浅滩边上一根一根地插路标桩，从 1 号编到 n 号，每根桩上钉一块牌子，写着自己的编号。这样夜里只要顺着编号数下去，就能安全靠岸。

请你帮帮Ottly，给路标桩编号吧。

**知识点讲解：**
1. 为什么需要"循环"
现在如果没有循环，要给 3 根桩编号，你得写三行：
```
print(1)
print(2)
print(3)
```
可桩数 n 是输入，写代码的时候你还不知道它到底是多少。

这里有个规律：要做的事完全一样（打印一个编号），只是每次用的数字不同。 凡是"同一件事重复做很多次"，就该交给循环。学循环之前，你只能一遍遍复制代码；学会循环之后，一行代码就能执行 n 次。

2. for 语句的骨架
```
for i in range(1, n + 1):
    print(i)
```
把它拆成四块：
```
for  i  in  range(1, n + 1)  :      ← 第一行：说明"要重复多少次"
     print(i)                        ← 缩进的一行：每次真正做的事
     └──────┬──────┘
        第二部分：循环体
└─┬─┘ └┬┘ └──────┬───────┘
  │    │         └── 第四部分：数数的范围（要数哪些数）
  │    └── 第三部分：循环变量，每一轮换成一个新数字
  └── 第一部分：关键字，读作"对于……中的每一个"
```
| 部分 | 作用 | 注意 |
|---|---|---|
| for | 说明"开始一个重复" | 三个字母都小写；不要写成 For 或 FOR |
| i | 循环变量，每一轮自动换成范围内的下一个数字 | 名字可以随便起，但习惯用 i；不能和 n 重名 |
| in | 读作"在……之中" | 前后各一个空格 |
| range(...) | 数数器，负责依次报出数字 | 括号是英文圆括号 |
| : | 行尾冒号，表示"下面缩进的就是要重复的内容" | 最容易漏的一个符号 |
| 缩进 | 决定哪些行属于循环体 | 用 4 个空格；不缩进的行只在循环结束后执行一次 |

3. range 的使用方法
range 是一个"数数器"，它接收起点和终点，从起点开始一个一个往后数，但永远数不到终点。
```
range(1, 4)     # 依次报出 1、2、3 ——  报不到 4！
终点是开区间：写作 range(起点, 终点)，实际给出的是"起点到终点减一"。
```
|写法|依次报出的数字|一共有几个|
| ---- | ---- | ---- |
|`range(3)`|0, 1, 2|3 个|
|`range(1, 4)`|1, 2, 3|3 个|
|`range(1, 8)`|1, 2, 3, 4, 5, 6, 7|7 个|
|`range(1, 1)`|（什么也不报）|0 个|
|`range(1, 0)`|（什么也不报）|0 个|

由此可以总结两条非常有用的规律：
1.循环次数 = 终点 − 起点。range(1, 8) 的次数是 8 − 1 = 7。
2.想数到 n，终点就要写 n + 1。这才是 range(1, n + 1) 里那个 + 1 的来历——把 n 本身包括进来。

为什么 Python 要这么"别扭"？因为这种"含头不含尾"的写法有两个好处：range(1, 8) 的次数一眼就是 8−1；而且从 0 开始时 range(n) 的次数正好是 n 次。习惯它以后会很方便。

4. range(n) 与 range(1, n + 1) 的区别
写法	报出的数字	适合做什么
range(n)	0, 1, 2, …, n−1	重复 n 次，不关心数字本身（比如"读 n 行输入"）
range(1, n + 1)	1, 2, 3, …, n	数字本身有意义（编号、第几天）
本关要打印的是编号，编号从 1 开始，所以必须用 range(1, n + 1)。如果写成 range(n)，n = 3 时会打印 0 1 2。

后面的关卡里你会经常看到 range(n)，那时它的任务是"把一件事做 n 次"，不是"编号"。

5. 循环变量 i 每一轮都在变
i 就是一个普通变量，只不过它是由 for 每轮自动重新赋值的：

第几轮	i 的值	执行 print(i) 的结果
第 1 轮	1	打印 1
第 2 轮	2	打印 2
第 3 轮	3	打印 3
第 n 轮 n	打印 n，循环结束
所以唯一的那一行 print(i) 被执行了 n 次，每次打印的数字不同。这正是前面"同一件事重复做，只是数字不同"的落地方式。

变量名用 i 只是全世界的习惯（来自 index，索引），你写 for num in range(1, n + 1) 或 for 桩号 in ... 完全正确，只要前后一致。

6. 缩进决定"哪些行被重复"
```
n = int(input())
for i in range(1, n + 1):
    print(i)
```
n = int(input()) 不缩进 → 只执行一次，在循环开始之前。
print(i) 缩进 → 属于循环体，执行 n 次。
如果没有把 print 缩进：
```
n = int(input())
for i in range(1, n + 1):
print(i)          # IndentationError：expected an indented block
```
Python 会直接报错，因为 for 冒号后面必须有一块缩进的循环体，不能是空的。

如果你写了两个 print，一个缩进一个不缩进：
```
for i in range(1, 4):
    print(i)      # 打印 1、2、3（三次）
print("靠岸")      # 只打印一次，在三次之后
```
缩进的重复、不缩进的只做一遍。

7. 特殊情况：n = 0 时"零次循环"
题面说 n 可以是 0（一根桩也不插）。代入 range(1, n + 1)：
```
n = 0  →  range(1, 1)  →  什么数字都不报
```
没有数字可报，循环体就一次都不执行，print 也就一次都不会跑。屏幕上不会出现 0、不会出现空行、不输出任何字符——这正好符合题面要求。

请不要为了"保险"在循环后面补一句 print(i) 或 print(0)：那会导致 n = 0 时多输出内容（或报 NameError），判题会判错。
"循环跑零次"是合法且常见的情况，不是错误。

**任务：**输入一个整数 n（0–100）。

使用 for 循环，把 1 到 n 每个数字单独一行依次输出。

n = 0 时不输出任何字符（不输出 0，也不输出空行）。

**样例：**
输入：
```
3
```
输出：
```
1
2
3
```

**参考解：**

```python
n = int(input())
for i in range(1, n + 1):
    print(i)
```

**三级提示：** L1：想让同一行代码重复执行，需要哪一种语句？L2：在纸上写出 range 实际会报出的第一个数和最后一个数。确定你写的范围里，n 本身被包进去了，n = 0 时它不会报数字。L3： 请让范围从 1 开始，终点写成 n 再加 1（因为终点不包含），把打印语句缩进到 for 下面，并确认 for 这一行末尾有冒号。写完用 n = 1、n = 0 各在脑子里跑一遍。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"3\n"` | `"1\n2\n3\n"` | 顺序和终点 |
| 隐藏 | `"0\n"` | `""` | 零次循环 |
| 隐藏 | `"1\n"` | `"1\n"` | 单次循环 |
| 隐藏 | `"5\n"` | `"1\n2\n3\n4\n5\n"` | 防止固定样例 |

## 第 08 关：收集贝壳总数

**前置与目标：** K07、K03；学习 K08。重点讲“更新后的总数 = 原总数 + 当前数”，初始化放在循环之前。本关讲解 += 是这一更新的简写，参考解保留完整写法。

**题面：** 输入 n（0–1000）。小海獭第 i 天收集 i 个贝壳，求第 1 天到第 n 天的总数。使用 for 循环逐项累加，不使用 sum 或等差数列公式。n=0 时输出 0，只输出最终总数。

**参考解：**

```python
n = int(input())
total = 0
for i in range(1, n + 1):
    total = total + i
print(total)
```

**详解：** n=4 时，total 从 0 依次变成 1、3、6、10。每次循环结束，它等于已经处理过的天数对应的贝壳总数。初始化只执行一次，输出在循环结束后执行一次。如果改成 total=i，每次都会丢弃之前的总数，最后只剩 4。n=0 时循环不执行，初始 0 就是答案。

**易错与复习：** 在循环内把 total 重置为 0；覆盖而非累加；range 漏终点；每次循环都输出。复习第 7 关范围、第 2 关赋值。

**三级提示：** L1：总数需要保留上一轮的结果吗？L2：跟踪前两轮 total 的值，检查初始化是否重复执行。L3：循环前准备初值，循环内把当前数加到已有总数，循环后再输出。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"4\n"` | `"10\n"` | 多步累加 |
| 隐藏 | `"0\n"` | `"0\n"` | 空范围与初值 |
| 隐藏 | `"1\n"` | `"1\n"` | 最小非空范围 |
| 隐藏 | `"100\n"` | `"5050\n"` | 原第 2 关回归样例 |

## 第 09 关：存够航行费

**前置与目标：** K08、K05；学习 K09。先讲 while 每轮前检查条件、状态变量必须推进，以及条件一开始为假时执行零次。

**题面：** 输入目标费用 target（0–3000）。初始存款为 0，每天结束时固定存入 3 个贝壳。使用 while 模拟，输出首次达到或超过目标需要的天数。目标为 0 时需要 0 天，不使用除法公式替代模拟。

**参考解：**

```python
target = int(input())
saved = 0
days = 0
while saved < target:
    saved = saved + 3
    days = days + 1
print(days)
```

**详解：** target=7 时，存款依次为 0、3、6、9，天数为 0、1、2、3。到 9 后，“存款不足目标”变成假，停止循环。target=6 时到第 2 天恰好达到目标，就不该再存一天。target=0 时一开始就不满足循环条件。

**易错与复习：** 写成 <= 多存一天；忘记更新 saved 导致不终止；只更新存款不增加天数。超时只是事实，只有看到循环缺少状态推进等代码证据，才可提示疑似终止问题。

**三级提示：** L1：什么时候还需要再存一天？L2：每轮检查存款和天数是否都发生变化，并试试目标为 0。L3：以“存款仍不足”为继续条件，一轮对应一天，刚达到目标就停止。

|---|---|---|---|
| 公开 | `"7\n"` | `"3\n"` | 最后一轮超过目标 |
| 隐藏 | `"0\n"` | `"0\n"` | 零次循环 |
| 隐藏 | `"1\n"` | `"1\n"` | 一天即可 |

## 第 10 关：电台字符统计

**前置与目标：** K02、K05、K08；学习 K10。讲 len 返回长度、字符串可直接逐字符遍历，并在循环中嵌入条件。比较字符时沿用第 5 关的 ==。

**题面：** 第一行输入一段长度 0–100 的文本 text，第二行输入一个目标字符 target。文本和目标仅包含英文字母或空格，区分大小写；文本允许为空，也允许首尾空格，目标恰好一个字符。使用 for 逐字符统计，不调用 count。输出两行：文本长度、目标字符出现次数。

**参考解：**

```python
text = input()
target = input()
count = 0
for char in text:
    if char == target:
        count = count + 1
print(len(text))
print(count)
```

**详解：** text 为 `banana`、target 为 `a` 时共检查 6 个字符，其中 3 次相等，所以输出 6 和 3。长度计算所有字符，包括空格；计数只计算匹配字符。input 会去掉行末换行，但不删除文本中的空格，因此不能额外 strip。空文本长度为 0，遍历零次，计数仍为 0。

## 第 11 关：温差记录表

**前置与目标：** K03、K05、K07；学习 K11。先演示空列表 []、append 添加一个元素、len 获取元素数、索引 0 表示第一项，以及直接遍历列表。特别讲 append 修改列表，不要把它的返回值再赋给列表。

**题面：** 第一行输入记录数 n（1–100），随后 n 行每行输入一个温差值（-100–100 的整数）。将记录存入列表，通过 for 遍历比较找出最大温差，只输出最大值。不使用 max 或排序。本题 n 至少为 1。

**参考解：**

```python
n = int(input())
values = []
for i in range(n):
    values.append(int(input()))
largest = values[0]
for value in values:
    if value > largest:
        largest = value
print(largest)
```

**详解：** 第一个循环把输入逐项保存。用第一条真实记录作为当前最大值；随后遍历，每遇到更大的值就更新。对于 -8、-3、-6，largest 从 -8 更新为 -3，最后保留 -3。如果初始设为 0，就会错误输出一个根本不存在的温差。再次比较第一项不影响正确性，也避免此时引入切片。

**易错与复习：** 用 0 初始化最大值；把 values[1] 当第一项，单元素时越界；忘记整数转换而按文本比较；将 append 返回值赋给列表。复习第 3 关类型、第 5 关比较。

**三级提示：** L1：当前最大值是否必须来自实际记录？L2：用全负数和只有一条记录的情况试走一遍。L3：从第一条记录开始保存候选最大值，再用每条数据更新；列表第一个位置编号是 0。

| 隐藏 | `"3\n-8\n-3\n-6\n"` | `"-3\n"` | 全负数 |
| 隐藏 | `"1\n-5\n"` | `"-5\n"` | 单元素和首索引 |

## 第 12 关：封装达标统计器

**前置与目标：** K05、K08、K11；学习 K12。先独立讲解 def、形参/实参、调用、return 与局部变量。明确 return 交回结果并结束本次调用，print 只显示内容。此关综合已学知识，不加入新容器或算法。

**题面：** 实现 `count_at_least(scores, threshold)`，返回列表中大于或等于 threshold 的分数个数。函数必须返回整数，不能在函数内用 print 代替 return，不修改 scores。第一行输入 n（0–100），第二行输入阈值 threshold（0–100），随后 n 行是 0–100 的整数分数。脚本调用该函数并输出返回值。

**脚手架安排：** 学生页面预先提供下面参考解中从 `n = int(input())` 开始的输入与调用部分，学生填写函数体。输入部分全是已学语法，保留可读；不要在脚手架中预先填入计数算法。

**参考解：**

```python
def count_at_least(scores, threshold):
    count = 0
    for score in scores:
        if score >= threshold:
            count = count + 1
    return count

n = int(input())
threshold = int(input())
scores = []
for i in range(n):
    scores.append(int(input()))
print(count_at_least(scores, threshold))
```

**详解：** 定义函数时不会立即统计；调用时，实参列表和阈值交给两个形参。count 在每次调用中重新从 0 开始。分数 59、60、80、100，阈值为 60 时，逐步计数为 0、1、2、3，循环结束后返回 3。外层 print 显示返回值。return 如果放到循环体内，会提前结束；如果换成 print，函数默认返回 None，外层可能额外输出 None。空列表遍历零次，仍应返回整数 0。

**易错与复习：** 打印代替返回；return 过早；用 > 漏掉恰好达标者；计数器放在函数外导致调用相互干扰；修改输入列表。复习第 5、8、11 关。

**三级提示：** L1：调用者需要拿到一个结果，这和屏幕上看见结果有何不同？L2：检查 return 的缩进，以及空列表是否也能走到返回位置。L3：在函数内初始化计数，遍历完所有分数后统一返回；由外层负责打印。

| 可见性 | 输入 JSON | 输出 JSON | 检查目的 |
|---|---|---|---|
| 公开 | `"4\n60\n59\n60\n80\n100\n"` | `"3\n"` | 混合情况与相等边界 |
| 隐藏 | `"0\n60\n"` | `"0\n"` | 空列表 |
| 隐藏 | `"3\n100\n0\n99\n99\n"` | `"0\n"` | 全部未达标 |
| 隐藏 | `"3\n0\n0\n50\n100\n"` | `"3\n"` | 全部达标、可变阈值 |
