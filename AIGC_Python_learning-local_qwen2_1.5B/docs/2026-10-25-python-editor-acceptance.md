# Python 编辑器实现与验证

## 已实现

- 主线与加练通过共用 `CodeEditor` 接入新组件；错题复习接入同一组件。
- Python关键字、字符串、数字、注释高亮；配对括号高亮。
- 圆括号、方括号、花括号及单双引号自动配对；跳过已有闭合符号；空配对删除。
- 块末冒号回车增加4个空格，其他行延续缩进；Tab与Shift+Tab支持多行缩进调整。
- Ctrl+Z撤销、Ctrl+Shift+Z或Ctrl+Y重做；Mac用Command+Z撤销、Command+Shift+Z重做。Esc后按Tab离开编辑器。
- 保留原有草稿保存、6000字限制、运行/提交只读、重置聚焦和反馈清理；题目或账号切换后重新创建编辑状态，撤销历史不跨文档。
- 编辑器按需下载，未打开编辑区的页面不提前加载CodeMirror。
- 保留工作区已有执行回放功能，不改判题、AI或数据接口。

## 尚未完成的人工验收

浏览器工具访问测试页时被页面访问策略拒绝，未尝试其他浏览器或间接方式绕过。因此没有进行真实浏览器键盘、实际中文输入法、手机触屏和窄屏布局验收。JSDOM使用模拟几何信息，只能证明DOM和事件逻辑，不能证明真实排版与输入法兼容性。

本机前端容器已更新。用户刷新原有页面后，可在主线、加练和错题复习分别检查：

1. 输入 `print(` 与引号，检查配对、光标位置及跳过闭合符号。
2. 输入 `if True:` 后回车，检查4空格缩进；试用Tab、Shift+Tab及撤销/重做。
3. 输入中文注释或字符串，确认没有重复或丢字。
4. 刷新后检查主线/加练草稿，切题或账号后检查代码与撤销历史隔离。
5. 运行/提交时检查只读，清空/恢复初始代码后检查聚焦。
6. 在窄屏检查长代码独立横向滚动，按钮仍可操作。
