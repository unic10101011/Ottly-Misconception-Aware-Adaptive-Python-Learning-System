## 怎么试

本机网站已更新。正常解锁第8关后，编辑器的“运行”旁边增加“执行回放”。可以选择打开时的编辑器代码，或本次已提交代码；输入 n 默认为3，可改成0～100。

面板逐行显示即将执行的位置、此前步骤执行后的变量、变量旧值→新值，以及真实输出。上一步、下一步、重新开始和进度条只读取已经采集的快照；返回做题保留原代码。

当前浏览器账号仅通过前两关，第8关仍遵守原解锁规则。为方便立即体验，另开本机演示 `http://127.0.0.1:3012/`：使用同一个 TracePlayer 组件，数据由独立 Python 进程真实采集，提供错误与正确两个示例切换。演示服务属于临时预览，关闭服务后此地址失效，不计入正式产品路由。

演示已补齐题目示意页与正式 `ExecutionReplay` 弹窗组件：右上角“返回做题”关闭弹窗，题目示意页“执行回放”再次打开。已在Chrome实际点击验证往返。此演示使用预采集数据适配器，仅支持两份示例及 n=3；正式API鉴权与执行测试仍独立记录，不把此预览当成真实账号端到端验收。

示例输入 n=3：

```python
n = int(input())
total = 0
for i in range(1, n + 1):
    total = i
print(total)
```

错误写法最终得到3；改为 `total += i` 最终得到6。拖动进度条可比较覆盖和累加的过程。

## 本轮范围

- 仅正式第8关 `shell-total-v1`，支持基本整数表达式、赋值、条件、分行 for/while、range、int(input()) 和 print。
- 不支持字符串、浮点常量、容器、函数定义、导入、属性访问、幂运算及单行多语句；暂未开放12关通用可视化。
- 真实采集通过独立子进程完成。限制代码长度6000字符、AST规模500节点、300步、6000字符输出、变量数量和数值大小；父进程3秒超时，Linux另设CPU与地址空间上限。达到限制明确标记轨迹不完整。这不是完整Python的安全执行环境。
- line事件为执行前；end为正常结束后；异常保留实际行号。语法/编译错误不生成执行步骤。
- 独立API保留登录、关卡解锁、提交归属校验。无判题、成绩、提交记录、学习进度写入，无模型请求。
- 暂未接AI讲解或自动定位错误原因；目前帮助学生自己看出每一步发生了什么。
