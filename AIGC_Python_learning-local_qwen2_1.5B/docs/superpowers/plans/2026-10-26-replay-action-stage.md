# 回放动作演示实施计划

**Goal:** 左侧代码、中间真实动作、右侧结果；先验证第2关，再覆盖第8关和通用事件。

**Architecture:** 隔离worker在快照中附加已完成动作，使用原始AST和同作用域前后原始标量，不执行额外用户表达式。表达式只支持常量、变量、简单加法，不能证明时回退变化摘要。前端纯展示已采集action；步进不运行代码、不自动请求AI。

**Tech Stack:** Python AST/sys.settrace、React、现有CSS、pytest、node:test。

## 约束

- 当前行保持执行前语义；动作明确标为上一行已执行完成，异常或跨作用域时不补造成功动作。
- 不改变普通判题、安全限制、账号进度、现有AI配置；本轮不提交或推送。
- 输入、字符串拼接和算式必须与已记录的实际值及实际输出一致。
