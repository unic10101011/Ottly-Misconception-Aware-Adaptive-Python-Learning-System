# 前四关执行回放试用与验收

后续已补齐正式12关，本文保留前四关首批记录；当前总体验收见 `docs/2026-10-25-all-lessons-execution-replay-acceptance.md`。

## 使用方式

正式网站第1～4关的代码区增加“执行回放”，沿用第8关的弹窗。左侧展示只读代码和即将执行的行，右侧展示此前步骤产生的变量、变化和真实输出；上一步、下一步、进度条和重新开始只读已采集快照。“返回做题”关闭弹窗，保留原草稿和运行输入。返回按钮与控制条在弹窗滚动时保持可见。

| 关卡 | 输入 | 演示内容 |
| --- | --- | --- |
| 1 初识小海獭 | 无 | print实际输出的文字、空格和标点 |
| 2 打招呼 | 一行姓名 | input得到的字符串、带引号的变量显示、拼接输出 |
| 3 贝壳小商店 | 单价/数量/支付金额，各一行 | 总价与差额逐步产生，比较误用加法与正确乘法 |
| 4 贝壳分组 | 数量/容量，各一行 | 整除与取余；误用普通除法时显示真实小数结果 |

打开回放时使用当前代码和当前运行输入；第1关无输入，第8关仍为0～100的n。弹窗支持重新填写输入再生成，代码版本可选当前快照或本次已提交版本。无效数值、输入不足、除零等按真实执行结果显示，不代替判题。

## 可直接打开的演示

`http://127.0.0.1:3012/first-four/` 为本机独立预览：四关可切换，选错误或正确示例，再点击“执行回放”；弹窗使用正式组件，右上角“返回做题”返回演示题目。

独立预览只展示各示例代码和页面所示输入的真实Python预采集数据，修改输入会明确提示该预览没有对应数据。正式网站才通过登录接口采集自己的代码和自选输入。预览不改账号进度、没有解锁绕过，临时服务停止后链接失效。

## 实现和边界

- API仅开放正式第1～4和8关，保留登录、原关卡解锁、提交归属与代码版本校验，无数据库写入、模型请求或判题调用。
- 前四关启用受限字符串、直接input和基本数值运算。字符串常量和输入包裹为受限文本，长度最多2000字符；左右重复先验证长度，字符串%格式化拒绝，属性/导入/容器/任意函数调用仍不开放。
- 第8关默认仍是原整数子集。原步数、输出、数值、变量、AST、超时及Linux资源限制保留。
- 不支持完整Python语法；关键字参数、字符串方法、格式化字符串等会说明超出范围，不虚构轨迹。尚未接AI逐步讲解。
- Unicode文本不作为协议分隔符，避免特殊姓名导致轨迹丢失。仅注释草稿不再显示不存在的“第0行”。
