# 浏览器直开运行说明

## 入口文件

- 双击打开 `frontend/index.html`
- 所有脚本与样式均使用相对路径加载
- 不依赖 Node.js、npm、React Native Metro 或本地 HTTP 服务

## 运行机制

- 页面使用原生 HTML + CSS + JavaScript
- 数据层通过 `localStorage` 模拟用户表、通知配置、登录设备、版本信息与文档缓存
- 为避免 `file://` 场景下的跨域限制，页面不再向本地后端发起网络请求
- 脚本采用普通 `script` 标签按顺序加载，避免 ES Module 在本地文件协议下的兼容问题

## 功能映射

- 账号与安全：验证码、绑定、密码强度、最近设备、远程登出
- 通知设置：总开关与三级子开关，服务端同步逻辑由本地模拟服务实现
- 清除缓存：浏览器存储中的缓存分桶扫描与清理，同时触发 `cacheCleared`
- 夜间模式：通过 `<html data-theme>` 与 CSS 变量即时换肤
- 语言选择：基于本地语言包即时切换中英文与格式化展示
- 关于我们：版本检查、更新日志、协议文档离线缓存与清除

## 注意事项

- 当前版本面向浏览器演示与本地评审，后端与数据库逻辑已被浏览器兼容方案替代
- 如需重置演示数据，可清除浏览器站点存储或删除 `localStorage` 对应键值
